# Small Tic-Tac-Toe

A responsive, keyboard-accessible two-player web game with win highlighting, draw detection, round scores, and reset controls. Scores last for the current page session.

## Run

Requires Python 3 and Node.js (for tests). No dependencies to install.

```sh
npm start
```

Serves the app on port 3000. Play by selecting an empty square; X starts each round. New round preserves scores. Reset scores clears scores and starts a new round.

```sh
npm test
```

The app uses native browser modules. Google Fonts is optional; system fonts work offline.
